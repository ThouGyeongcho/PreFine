# PreFine v0.1.2 Frontend Finalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reproduce the approved login and money-page designs in the formal frontend, publish the transparent on-dark brand asset, and release the verified result as v0.1.2.

**Architecture:** Keep authentication and money APIs unchanged. `AppShell` selects a purpose-specific transparent PNG for the dark sidebar, while `MoneyPage` owns a stable two-panel workbench, one shared copy-button contract, and three equal auxiliary result cards. GitHub Actions remains the only Docker image builder; local work ends with source verification, followed by `main` and annotated-tag publication.

**Tech Stack:** React 19, TypeScript 5.9, Vite 7, Vitest/React Testing Library, Playwright, Python 3.12/pytest, GitHub Actions, GHCR.

## Global Constraints

- Preserve the approved login page from `docs/superpowers/specs/2026-07-26-prefine-login-page-refresh-design.md` without changing its dimensions or copy.
- Treat `docs/superpowers/specs/2026-08-01-prefine-v0.1.2-design.md` as the exact visual and release contract.
- Keep all money calculations and API response fields unchanged; use no binary floating point.
- Add no runtime dependency, font, icon library, database change, or authentication change.
- Use `/prefine-logo-512.png` on the login page and `/prefine-logo-on-dark-512.png` in the dark sidebar.
- Build no Docker image locally. GitHub Actions builds `linux/amd64` and `linux/arm64` for `latest` and `0.1.2`.
- Work directly on `main`, as explicitly requested; do not create a feature branch or pull request.
