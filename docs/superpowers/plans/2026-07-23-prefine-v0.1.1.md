# PreFine v0.1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release PreFine v0.1.1 with corrected branding, a visually aligned “金额转换” workspace, tolerant “圆” parsing, reliable copying, and exact auxiliary amount representations.

**Architecture:** Keep every monetary transformation in `backend/app/money.py` using `Decimal`, expose one additive response shape from both money endpoints, and let React render that shape without recalculation. Isolate clipboard fallback and colored amount-token rendering into small frontend units, then update the existing tag-driven release pipeline to consume a single-version release-note file.

**Tech Stack:** Python 3.12, FastAPI, Pydantic v2, pytest, React 19, TypeScript, Vite, Vitest/Testing Library, Playwright, GitHub Actions.

## Global Constraints

- Preserve the visual rules in `docs/superpowers/specs/2026-07-21-prefine-design.md`: `#3E6AE1`, 4px controls, 12px cards, no shadows, 40px buttons, visible keyboard focus.
- Use `Decimal` for every monetary calculation; JavaScript must not derive amount values.
- Accept only the additional “圆” alias; keep all other uppercase validation strict.
- Quick reading is exact four-digit positional grouping, never scaled or rounded.
- English output is complete sentence-case wording such as `One million yuan only`, never all caps.
- Reuse `assets/branding/prefine-logo-512.png`; do not create a new Logo design.
- Keep deployment pull-only and single-worker; local work must not build a Docker image.
- Release notes contain only v0.1.1 changes.
